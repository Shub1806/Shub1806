## 📏 LLM Evaluation Harness · `Python` `pytest` `SQLite` `Statistics`
 
> A reproducible framework for comparing multiple language models on the same tasks.
 
- Pluggable, provider-agnostic model interface with mock providers for deterministic testing.
- Results persisted to SQLite for repeatable, auditable runs.
- Statistical comparison built in: **McNemar's test** for paired accuracy and **Cohen's kappa** for agreement.
- CLI-driven workflow, built on the Python standard library plus pytest.
